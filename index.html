Tự Động Hóa Trực Tiếp Trên Google Sheets

Dán đoạn mã **Google Apps Script** dưới đây vào Google Sheets của bạn để dùng hàm tự động `=SHOPEE_AFF(A2, "facebook", "post")`:

/**
 * Hàm tự động tạo Link Affiliate Shopee chuẩn trong Google Sheets
 * Cú pháp: =SHOPEE_AFF(shopeeUrl, sub1, sub2, sub3)
 */
function SHOPEE_AFF(shopeeUrl, sub1, sub2, sub3) {
  var AFFILIATE_ID = "14354840000"; // Thay mã ID Affiliate của bạn ở đây
  if (!shopeeUrl) return "";
  
  var encodedUrl = encodeURIComponent(shopeeUrl);
  var subIds = [];
  if (sub1) subIds.push(sub1);
  if (sub2) subIds.push(sub2);
  if (sub3) subIds.push(sub3);
  
  var subStr = subIds.join("-");
  var result = "https://s.shopee.vn/an_redir?origin_link=" + encodedUrl + "&affiliate_id=" + AFFILIATE_ID;
  if (subStr) {
    result += "&sub_id=" + subStr;
  }
  return result;
}

Tự Động Hóa Với Telegram Bot

Bot Telegram giúp bạn gửi bất kỳ link Shopee nào vào khung chat, Bot sẽ tự động trả lại link Affiliate rút gọn trong 1 giây.

import urllib.parse
from telegram import Update
from telegram.ext import ApplicationBuilder, CommandHandler, MessageHandler, filters, ContextTypes

AFFILIATE_ID = "14354840000"
TELEGRAM_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN_HERE"

async def convert_link(update: Update, context: ContextTypes.DEFAULT_TYPE):
    text = update.message.text
    if "shopee.vn" in text or "shope.ee" in text:
        encoded_url = urllib.parse.quote(text.strip(), safe='')
        aff_link = f"https://s.shopee.vn/an_redir?origin_link={encoded_url}&affiliate_id={AFFILIATE_ID}&sub_id=telegram-bot"
        await update.message.reply_text(f"🚀 Link Affiliate Shopee của bạn:\n\n{aff_link}")
    else:
        await update.message.reply_text("Vui lòng gửi đúng đường dẫn Shopee hợp lệ.")

if __name__ == '__main__':
    app = ApplicationBuilder().token(TELEGRAM_BOT_TOKEN).build()
    app.add_handler(MessageHandler(filters.TEXT & (~filters.COMMAND), convert_link))
    print("Bot đang hoạt động...")
    app.run_polling()
