Cấu Hình Ma Trận Sub-ID Tracking

Quản lý các danh mục phân loại để theo dõi nguồn doanh thu chi tiết từ Shopee Analytics.

Cấu trúc Sub-ID chuẩn của Shopee (tối đa 5 Sub-ID):
sub_id = [Kênh Quảng Bá] - [Chiến Dịch] - [Dạng Nội Dung] - [Vị Trí] - [Mã Nhận Diện]

Sub-ID 1: Kênh Quảng Bá (Source)

  • facebook_page - Fanpage Sài Gòn Cá Cảnh
  • facebook_group - Hội Nhóm Thủy Sinh
  • tiktok_bio - Link Bio Trang TikTok
  • youtube_short - Kênh YouTube Shorts
  • zalo_oa - Nhóm Zalo Khách Hàng

Sub-ID 2: Loại Chiến Dịch (Campaign)

  • sale_payday - Khuyến mãi Lương Về
  • sale_double_day - Siêu sale ngày đôi (8.8, 9.9)
  • flash_sale - Deal chớp nhoáng hàng ngày
  • koc_collection - Bộ sưu tập KOC chọn lọc

Hướng Dẫn Cài Đặt Chrome Extension v2.3.3

Tiện ích mở rộng tạo link 1-Click & Đồng bộ siêu tốc 64+ sản phẩm từ Shopee vào Siêu Thị.

  1. Tải thư mục chrome-extension/ trong mã nguồn của bạn về máy tính.
  2. Mở trình duyệt Google Chrome hoặc Cốc Cốc, truy cập đường dẫn: chrome://extensions/
  3. Bật công tắc "Chế độ dành cho nhà phát triển" (Developer Mode) ở góc trên bên phải.
  4. Bấm nút "Tải tiện ích đã giải nén" (Load unpacked) và chọn thư mục chrome-extension/.
  5. Khi lướt Shopee, mở Extension và bấm nút vàng "📸 Đồng Bố Trang Này Vào Siêu Thị".

Tích Hợp Google Sheets (Mã Nguồn Apps Script)

Sử dụng hàm =CREATE_SHOPEE_AFF(url, sub1, sub2) trực tiếp trên Bảng tính.

Dán đoạn mã sau vào menu Tiện ích mở rộng > Apps Script trong Google Sheets của bạn:

/**
 * Hàm tạo link Shopee Affiliate tự động trên Google Sheets
 * @param {string} rawUrl Link Shopee gốc
 * @param {string} sub1 Nguồn quảng bá (mặc định: google_sheets)
 * @param {string} sub2 Tên chiến dịch
 * @return Link Affiliate hoàn chỉnh
 * @customfunction
 */
function CREATE_SHOPEE_AFF(rawUrl, sub1, sub2) {
  if (!rawUrl || rawUrl === "") return "";
  var affId = "17384730538";
  var encodedUrl = encodeURIComponent(rawUrl.toString().trim());
  var sub1Val = sub1 ? sub1.toString().trim() : "google_sheets";
  var sub2Val = sub2 ? sub2.toString().trim() : "sheet_report";
  
  return "https://s.shopee.vn/an_redir?origin_link=" + encodedUrl + 
         "&affiliate_id=" + affId + 
         "&sub_id=" + sub1Val + "-" + sub2Val;
}

Tích Hợp Telegram Bot (Python Source Code)

Bot tự động phản hồi link Affiliate ngắn khi quăng link vào khung chat.

Chạy file Python trên máy chủ hoặc máy tính cá nhân để kích hoạt Bot Telegram:

import urllib.parse
from telegram import Update
from telegram.ext import ApplicationBuilder, CommandHandler, MessageHandler, filters, ContextTypes

AFFILIATE_ID = "17384730538"
TELEGRAM_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN_HERE"

async def convert_link(update: Update, context: ContextTypes.DEFAULT_TYPE):
    text = update.message.text
    if "shopee.vn" in text or "shope.ee" in text:
        encoded_url = urllib.parse.quote(text.strip(), safe='')
        aff_link = f"https://s.shopee.vn/an_redir?origin_link={encoded_url}&affiliate_id={AFFILIATE_ID}&sub_id=telegram-bot"
        await update.message.reply_text(f"🚀 Link Affiliate Shopee của bạn:\n\n{aff_link}")
    else:
        await update.message.reply_text("Vui lòng gửi đúng đường dẫn Shopee hợp lệ.")

if __name__ == '__main__':
    app = ApplicationBuilder().token(TELEGRAM_BOT_TOKEN).build()
    app.add_handler(MessageHandler(filters.TEXT & (~filters.COMMAND), convert_link))
    print("Bot đang hoạt động...")
    app.run_polling()
